# Dataset wilayah Indonesia

`indonesia_regions.csv.gz` memuat hierarki provinsi, kabupaten/kota, kecamatan,
dan desa/kelurahan sesuai Kepmendagri No. 300.2.2-2138 Tahun 2025. Kode pos
dipetakan pada tingkat desa/kelurahan.

Sumber data:

- https://github.com/cahyadsn/wilayah
- https://github.com/cahyadsn/wilayah_kodepos

eksternal ketika checkout.
